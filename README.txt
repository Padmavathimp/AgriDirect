AGRIDIRECT - STARTER WEBSITE

1. Extract the AgriDirect folder.
2. Open the extracted folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click index.html and choose "Open with Live Server".

This is the Step 1 starter interface. Login, registration, marketplace data,
Firebase, orders, and payments are placeholders and will be implemented
step by step. The hero background image requires an internet connection.
